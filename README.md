# 📚 Exercícios da Faculdade

Repositório com exercícios desenvolvidos em sala de aula utilizando **HTML, CSS e JavaScript**, como parte da prática em programação web.

## 📌 Sobre

Este repositório contém uma coleção de exercícios práticos que fiz durante as aulas da faculdade, focados em desenvolvimento front-end com HTML, CSS e JavaScript. É um espaço para organizar meus códigos e acompanhar minha evolução no aprendizado web.

## 🧠 Conteúdo

Atualmente o repositório inclui:

- 🟩 **Ex001.html** – Exercício 1  
- 🟦 **Ex002.html** – Exercício 2  
- 🟨 **Exe003.html** – Exercício 3  
- 🟪 **Exe004.html** – Exercício 4  
- 🖼️ **img/** – Imagens relacionadas aos exercícios  
- 📄 **index.html** – Página de índice ou exemplos adicionais

> 📂 Os nomes dos arquivos estão organizados conforme a numeração dos exercícios.

## 🚀 Tecnologias Usadas

Este projeto utiliza:

- 🧱 **HTML** — Marcação de conteúdo  
- 🎨 **CSS** — Estilização visual  
- 💻 **JavaScript** — Interatividade e lógica
